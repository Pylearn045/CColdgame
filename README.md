# Command & Conquer: Tiberian Dawn Clone

用 Python + Pygame 实现的第一代《命令与征服》复刻版（单文件游戏）。

## 游戏截图

启动游戏即可看到：48x48 格地图、GDI 基地（左下）vs NOD 基地（右上），含 Tiberium 矿场、建筑、单位和完整对战逻辑。

## 系统要求

- Python 3.8+
- Pygame 2.5+

## 快速开始

`ash
# 安装依赖
pip install pygame

# 运行游戏
python game.py
`

Windows 用户也可以直接双击 
un.bat。

## 操作说明

| 操作 | 说明 |
|---|---|
| 鼠标左键 | 选取单位或建筑 |
| 左键拖拽 | 框选多个单位 |
| 鼠标右键 | 移动 / 攻击敌人 |
| WASD / 方向键 | 滚动地图 |
| 鼠标移至屏幕边缘 | 自动滚屏 |
| F1 / H | 显示/隐藏操作帮助 |
| R | 游戏结束后重新开始 |
| ESC | 退出游戏 |

## 游戏内容

### 阵营
- **GDI**（玩家控制）— 蓝色阵营，左下角基地
- **NOD**（AI 控制）— 红色阵营，右上角基地

### 建筑（通过侧边栏建造）
| 建筑 | 费用 | 说明 |
|---|---|---|
| 建造场 (Construction Yard) |  | 建造其他建筑的基础 |
| 发电厂 (Power Plant) |  | 提供电力 |
| 兵营 (Barracks) |  | 训练步兵单位 |
| 冶炼厂 (Refinery) |  | 精炼 Tiberium 兑换资金 |
| 兵工厂 (War Factory) |  | 制造载具单位 |

### 单位
| 单位 | 费用 | 类型 | 说明 |
|---|---|---|---|
| 机枪兵 (Minigunner) |  | 步兵 | 基础作战单位 |
| 火箭兵 (Rocket Soldier) |  | 步兵 | 反载具，射程远 |
| 轻型坦克 (Light Tank) |  | 载具 | 高伤害主力 |
| 收割者 (Harvester) |  | 载具 | 自动采集 Tiberium |

### 经济系统
1. 收割者自动寻找地图上的 Tiberium 晶体
2. 到达后自动采集（每车最多 10 单位）
3. 装满后自动返回最近的冶炼厂卸货
4. 每单位 Tiberium 价值 

### AI 对手
NOD 阵营会自动：
- 建造发电厂、兵营、冶炼厂、兵工厂
- 训练步兵和坦克部队
- 积累兵力后主动进攻玩家基地

## 技术实现

- **引擎**: Pygame 2.6+
- **渲染**: 纯几何绘图（矩形、圆形、多边形），无外部图片资源
- **寻路**: A\* 算法，支持 8 方向移动
- **地图**: 48x48 瓦片网格（1536x1536 像素），程序化生成地形
- **战斗**: 实时单位对战，含弹道投射物动画
- **UI**: 右键侧边栏 + 小地图 + 单位/建筑信息面板
- **帧率**: 60 FPS
