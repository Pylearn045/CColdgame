Add Unity map import/export tools, pixel tiles, and map preview

- Exporter: export_map.py supports custom sizes (up to 128) and discrete height levels
- Unity Editor: Unity/Editor/MapImporter.cs to load JSON and generate preview GameObjects
- Pixel art assets: assets/tiles + assets/transitions (32px) generated by tools/generate_tiles_pixel.py
- Tools: tile generators and preview renderer under tools/
- Example maps: map_96x96.json, map_96x96_L4.json and preview image
- Run helper: run_game.py to run the original Pygame prototype

Notes:
- MapImporter uses Newtonsoft.Json in Unity; set texture Filter Mode to Point for pixel-art.
- Follow-ups: convert preview to Unity Tilemap and refine transition shader.
